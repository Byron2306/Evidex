# EVIDEX assets

Place your logo file here so the desktop UI can load it.

Recommended filename:
- `assets/evidex_logo.png`

Optional override:
- Set `EVIDEX_LOGO_PATH` to a full path to a PNG file.

Notes:
- Tkinter’s built-in `PhotoImage` supports PNG.
- Keep a square logo (e.g., 256×256 or 512×512) for best results.
