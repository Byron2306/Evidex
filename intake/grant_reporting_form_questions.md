# Intake form (Google Form) — Grant Reporting Evidence Pack

Goal: collect only what’s needed to generate an audit-ready evidence pack within 48 hours.

## Section A — Contact + delivery
1. Your name
2. Organization
3. Role (Program Manager / M&E / Finance / Consultant)
4. Email for delivery
5. Time zone
6. Deadline date/time
7. Confidentiality: confirm you have the right to share the uploaded materials (Yes/No)

## Optional Section A2 — Billing (for corporate + consultancies)
If you want invoices to reflect corporate/consultancy pricing automatically, collect:
8. Client type (NGO/grant-funded / Corporate / Consultancy)
9. Order size (packs) (1 / 5 / 10)
10. Currency (USD / ZAR / other)

Implementation note: map these to `billing.client_type`, `billing.quantity`, `billing.currency` in `intake.yaml`.

## Section B — Pack type
11. Pack purpose (choose one)
- Donor funding report
- Annual audit support
- Tax/VAT compliance evidence
- Internal controls / compliance
- ESG/CSI reporting support
- University grant closeout / research compliance
- Board update

12. Stakeholder / funder name (optional) (donor, auditor, regulator, board committee)
13. Grant / project name
14. Grant ID (optional)
15. Reporting period start date
16. Reporting period end date

## Section C — KPIs (evidence table)
17. Provide KPIs in one of these ways:
- Upload KPI spreadsheet (preferred)
- Or paste KPIs (one per line) with target + actual

If pasting, ask:
18. KPI name
19. Target
20. Actual
21. How measured (source system / field forms / finance records)

## Section D — Required narrative
22. Tone (formal / neutral / donor-friendly)
23. Required headings (if donor template exists)
24. Risk sensitivities (anything we must avoid stating)
25. Red flags (known gaps / missing docs)

## Section E — Uploads
26. Uploads (recommended for full automation)

Option A (best): **Google Forms “File upload” question** (allow multiple files)
- KPI sheet / logframe
- Activity reports
- Financial summary
- Receipts/invoices list
- Meeting minutes
- Monitoring visit notes
- Key email threads (optional)

Option B (fallback): Upload folder link (Drive/OneDrive)
- If Google Drive folder link: can be copied automatically (requires access)
- If OneDrive link: usually requires manual download/copy to keep it private and reliable

## Section F — Output preferences
27. File format preference
- DOCX + XLSX (default)
- PDF (optional; requires conversion on your side or extra tooling)

28. Include appendix summaries (Yes/No)
29. White-label naming (your brand name to appear on the cover, optional)
